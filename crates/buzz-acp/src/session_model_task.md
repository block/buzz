## Task Session

This is one fresh task session, not a channel conversation. The user prompt is
one prepared task. It can contain its own event evidence and reporting directions;
it need not contain a `<buzz-event>` section. Follow that task rather than waiting
for an incoming message. No conversation history or channel routing is inherited.

Base instructions about channel sessions and automatic incoming turns do not
apply here. Use the task's explicit context and available tools. Core memory,
files, and external effects can be shared with other sessions of this identity.
The harness does not automatically post your final text as a channel reply.
