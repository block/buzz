# Archived failed deployment experiment

This directory preserves the files from a failed Launchpad VPS deployment
method.

> **Historical reference only. Do not use anything in this directory to build
> or deploy Buzz.**

The experiment was based on an incomplete understanding of the files involved
in the deployment path and of which image-selection values were hard-coded. It
ultimately defaulted to the Block test relay image rather than reliably mapping
the deployment to `launchpad-26/buzz`. The old files are retained to support
postmortem learning and prevent the same approach from being repeated.

Historical documents have been renamed accordingly. Their old instructions are
not authoritative and must not be followed.
