# Admin Web

Web-based admin dashboard for relay operators. Provides a graphical interface for administrative tasks.

**Capabilities:**
- Community management (create, configure, delete)
- Channel administration
- Member management
- Audit log viewer
- System health monitoring
- Configuration editing
