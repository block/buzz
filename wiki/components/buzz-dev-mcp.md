# buzz-dev-mcp

MCP (Model Context Protocol) server providing shell and file-edit tools. Intended for development agents that need to interact with the filesystem.

**Tools provided:**
- Shell command execution
- File read/write/edit operations
- Directory listing

Uses the **rmcp** SDK (Rust MCP implementation).
