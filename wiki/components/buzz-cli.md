# buzz-cli

Agent-first CLI tool. Designed for LLM tool calls — JSON in, JSON out. Every command accepts structured input and returns structured output.

**Use cases:**
- Querying channel messages
- Sending messages programmatically
- Managing channels and memberships
- Triggering workflows
- Integration with agent subprocesses

The CLI is the recommended way for agents to interact with Buzz when they need more structured control than real-time messaging provides.
