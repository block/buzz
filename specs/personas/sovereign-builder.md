# Persona: Sovereign builder

## Role

One person building durable shared memory with accountable agents on a node
they own. The builder works through many surfaces — a CLI, a desktop app, and
several agent harnesses on the same laptop — and expects all of them to be
windows into the same room. Distinct from the sovereign node operator: the
operator keeps the node trustworthy; the builder inhabits it.

## Goals

- Re-enter any bounded context and be oriented in under a minute, from any
  surface, without recalling addresses or slugs.
- Leave attention residue as a side effect of working, not as a closing
  ceremony that competes with the next thing.
- See current understanding and live threads separately from raw history.
- Know at a glance who contributed what: which agent, on which machine,
  under which verified authority — especially where counterpart identities
  write into the same context.
- Trust that the node remembers attention, not merely events.

## Frustrations

- A week of intense work compresses into one context head because saving is
  manual and the boundary is a naming convention.
- Re-entry serves a transcript when what is needed is an orientation.
- Remembering the slug is a prerequisite for remembering the work.
- Session logs are faithful breadcrumbs but a trail is not a room.
- Contributions from different agents and counterparties blend together
  unless provenance is deliberately displayed.
- Multi-node protocols keep advancing while the solo experience stays raw.

## Context

- Tech comfort: high
- Usage frequency: daily, across several agent sessions per day
- Key devices: primary laptop (multiple agent harnesses, CLI, desktop app);
  a second machine reached later through ordinary software distribution

## Quotes

> "Where were we — and what changed while I was gone, and who says so?"
