# Desktop Agent Guide

The repository-root `AGENTS.md` still applies.

Before changing the desktop application:

1. Read [`../docs/agent-guides/desktop.md`](../docs/agent-guides/desktop.md).
2. For screenshots, Playwright capture, or other visual evidence, also read
   [`../docs/agent-guides/pr-screenshots.md`](../docs/agent-guides/pr-screenshots.md).
3. Read any more specific `AGENTS.md` between `desktop/` and the files you will
   change.

Keep desktop-specific rules here or in the linked guide. Do not copy them back
into the always-loaded repository root.
