# Agent Configuration Contributor Rules

The repository-root and `desktop/AGENTS.md` instructions still apply.

Before changing how harness, provider, model, effort, persona, access, or
managed-agent configuration is modeled, rendered, persisted, or applied, read
[`../../../../docs/agent-guides/desktop-agent-configuration.md`](../../../../docs/agent-guides/desktop-agent-configuration.md).

That guide is the detailed contract and must be updated in the same change when
configuration behavior or its invariants change. Keep this file as a small
scope router so the detailed contract is loaded deliberately instead of
truncating the automatic instruction chain.
