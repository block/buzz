# Business Core B4

B4 turns confirmed-shipment revenue and frozen shipment cost into rebuildable,
append-only profit facts. It adds deterministic operational-cost allocation,
order contribution/management profit, scoped profitability dimensions, and
immutable management-report snapshots.

This is a management view, not a general ledger, statutory financial statement,
tax return, invoice subledger, or bank reconciliation. Humans write adjustments
through BusinessSession + Origin + CSRF + idempotency + expected version. Agents
and service identities remain read-only.

The authoritative migration is `0008_business_core_b4_profitability_management_reporting.sql`.
Run `just business-b4-check`; the real PostgreSQL flow is opt-in through
`BUSINESS_CORE_B4_TEST_DATABASE_URL` and must target a disposable database.
