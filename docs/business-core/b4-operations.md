# B4 operations

Enable B4 features and the projection worker independently. Monitor projection
offset age, pending/retried failures, reconciliation differences, unallocated
expense, report source watermarks and API latency. A disabled worker must yield
`partial`, never fixture fallback. Rebuild is safe and idempotent. Do not mutate
facts or snapshots to repair data: reverse the business source or post an
authorized operational adjustment.
