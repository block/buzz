# ADR 023：商品换算规则独立治理，交易接入必须保存快照

## 状态

已接受。

## 决策

商品基础单位是库存数量与成本的权威单位。采购或销售替代单位使用商品级换算规则表达，因子定义为一替代单位折合的基础单位数量，并限定采购、销售或两者适用。

换算规则可受控修订，但历史交易不得回溯使用最新因子。交易页面接入替代单位时，订单行必须同时保存选择单位、换算因子快照、原始数量和标准化基础数量；库存、履约与成本只使用基础数量。

## 原因

箱规、包装和促销规格会随时间变化。只保存单位标识并在读取时查询当前因子，会静默改写历史订单数量、库存与利润含义。

## 后果

- 本阶段先建立权威换算目录和停用规则，现有交易仍限定基础单位。
- 下一阶段交易接入需要扩展订单行快照，而不是直接替换现有数量字段。
- 已被未完成订单使用的换算规则不能停用。
