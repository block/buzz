# 한국어 표현과 번역 경계

| 원문 | 표기 |
|---|---|
| Settings / Appearance | 설정 / 모양 |
| Inbox | 받은 편지함 |
| Agent / Agent team | 에이전트 / 에이전트 팀 |
| Community / Relay | 커뮤니티 / 릴레이 |
| Channel / Thread / Direct message | 채널 / 스레드 / 다이렉트 메시지 |
| Harness / Provider / Model | 하네스 / 제공자 / 모델 |
| Permission / Owner / Operator | 권한 / 소유자 / 운영자 |
| Start / Stop / Restart | 시작 / 중지 / 재시작 |
| Archive / Restore / Delete | 보관 / 복원 / 삭제 |
| Workflow / Trigger / Step | 워크플로 / 트리거 / 단계 |

버튼은 짧은 동작 이름을 쓰고, 설명은 해요체 또는 합니다체를 문맥에 맞게 사용합니다. 삭제·권한·신원 복구 안내는 원문의 대상과 결과를 생략하지 않습니다. 영문 복수형의 `s`를 한국어 변수로 노출하지 않고 개수와 명사를 완전한 문장 안에서 표현합니다.

제품명, 제공자·모델명, 명령어, 환경 변수 이름, URL, 경로, 파일명과 사용자 지정 이름은 원문을 유지합니다. 사용자 메시지·코드·에이전트 지침·응답·검색어에도 번역을 적용하지 않습니다. 프로토콜의 상태 판정값과 저장되는 enum은 고정하고 화면에 표시할 때만 번역합니다.

날짜는 현재 언어의 Intl formatter로 표시하며 저장된 Unix timestamp는 바꾸지 않습니다. 워크플로 조건은 구조화된 조건에서 한국어 설명을 만들고, 따옴표 안의 사용자 값은 그대로 둡니다. OS 소유의 파일 선택·키체인·권한 창과 외부 프로그램의 원문 오류는 해당 시스템의 언어를 따릅니다.
