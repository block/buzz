# ORBIT Agent Instructions

These files define the roles used by AI coding agents. They complement the root `AGENTS.md`.

- `FEATURE_EXECUTOR.md` — implement one feature.
- `FEATURE_COMPLETION.md` — completion gate after a feature is built.
- `REVIEWER.md` — review implementation and specification compliance.
- `TESTER.md` — design/run local tests and record evidence.
- `RELEASE_MANAGER.md` — local packaging/release validation before CI/CD.
