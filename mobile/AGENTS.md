# Mobile Agent Guide

The repository-root `AGENTS.md` still applies.

Before changing the Flutter application:

1. Read [`../docs/agent-guides/mobile.md`](../docs/agent-guides/mobile.md).
2. For simulator screenshots or other visual evidence, also read
   [`../docs/agent-guides/pr-screenshots.md`](../docs/agent-guides/pr-screenshots.md).
3. Read any more specific `AGENTS.md` between `mobile/` and the files you will
   change.

Keep mobile-specific rules here or in the linked guide. Do not copy them back
into the always-loaded repository root.
